# Şifre Güvenliği Kontrol Sistemi | Password Security Checker

[🇹🇷 Türkçe](#türkçe) | [🇬🇧 English](#english)

## Türkçe

Şifrelerin temel güvenlik ölçütlerini kontrol eden, tarayıcıda çalışan basit bir web uygulaması.

### Özellikler

- Şifre gücünü yazarken anlık değerlendirir.
- En az 12 karakter, küçük harf, büyük harf, rakam ve sembol ölçütlerini kontrol eder.
- Şifreyi gösterme veya gizleme seçeneği sunar.
- Bazı yaygın şifre kalıplarına karşı uyarı verir.
- Telefon ve bilgisayar ekranlarına uyumlu bir arayüze sahiptir.

### Gizlilik

Şifre kontrolü tarayıcında yapılır. Şifren sunucuya gönderilmez veya uygulama tarafından kaydedilmez.

### Nasıl Çalıştırılır?

Ek kurulum gerekmez. `index.html` dosyasını tarayıcıda açman yeterlidir.

### Dosyalar

- `index.html` — Sayfa yapısı
- `style.css` — Görünüm ve sayfa düzeni
- `script.js` — Şifre kontrolleri ve etkileşimler

### Sınırlamalar

Bu uygulama temel ölçütlere ve bilinen birkaç yaygın kalıba göre değerlendirme yapar. Bir şifrenin kesinlikle güvenli olduğunu garanti etmez. Her hesap için farklı ve benzersiz şifre kullan.

## English

A simple browser-based web application that checks passwords against basic security criteria.

### Features

- Evaluates password strength as you type.
- Checks for at least 12 characters, lowercase and uppercase letters, a number, and a symbol.
- Lets you show or hide the password.
- Warns about a few common password patterns.
- Includes a responsive interface for desktop and mobile screens.

### Privacy

Password checks run in your browser. Your password is not sent to a server or saved by the application.

### How to Run

No installation is required. Open `index.html` in a web browser.

### Files

- `index.html` — Page structure
- `style.css` — Styling and layout
- `script.js` — Password checks and interactions

### Limitations

This application uses basic criteria and checks for a small set of common patterns. It cannot guarantee that a password is completely secure. Use a different, unique password for every account.
