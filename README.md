# Şifre Güvenliği Kontrol Sistemi

Tarayıcı içinde çalışan, yazılan şifrenin temel güç ölçütlerini kontrol eden küçük bir web uygulaması.

## Gizlilik

Şifre yalnızca kullanıcının tarayıcısında değerlendirilir. Uygulama şifreyi sunucuya göndermez veya kaydetmez.

## Özellikler

- Şifre gücünü anlık gösterir.
- Uzunluk, küçük harf, büyük harf, rakam ve sembol ölçütlerini kontrol eder.
- Şifreyi gösterme/gizleme düğmesi içerir.
- Yaygın bazı şifre kalıplarına karşı uyarı verir.
- Telefon ve masaüstü ekranlarına uyumlu arayüze sahiptir.

## Çalıştırma

`index.html` dosyasını tarayıcıda açman yeterlidir. Ek kurulum veya API anahtarı gerekmez.

## Dosyalar

- `index.html` — Uygulama yapısı
- `style.css` — Görünüm ve sayfa düzeni
- `script.js` — Şifre kontrolleri ve etkileşimler
